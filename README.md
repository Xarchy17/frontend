# Anna Brew PO Management

Aplikasi manajemen purchase order berbasis Next.js App Router.

## Menjalankan aplikasi

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`. Perintah produksi:

```bash
npm run build
npm start
```
